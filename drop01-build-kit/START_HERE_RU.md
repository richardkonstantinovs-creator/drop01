# Как с этим работать

В этой папке всё, что нужно Claude Code, чтобы собрать рабочую систему: вейтлист, магазин, дашборд и CRM. На выходе получится один zip-файл для GoDaddy.

## Что внутри

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Главное техническое задание. Claude Code читает его сам при каждом запуске. |
| `PROMPTS.md` | Готовые команды для Claude Code — по одной на каждый этап. |
| `prototypes/` | Утверждённые дизайны: `waitlist.html`, `shop.html`, `waitlist-dashboard.html`, `crm.html`. По ним Claude Code делает настоящую версию. |
| `OWNER_INPUT.md` | Твои реальные данные: название, KvK, товары, цены, зоны доставки. Заполняй по мере готовности. |

## Шаги

1. **Распакуй** этот zip в отдельную папку на компьютере, например `Documents/drop01`.
2. **Открой Claude Code** в этой папке. Подойдёт любой вариант:
   - **Приложение Claude** для Mac или Windows: вкладка **Code**, выбери эту папку;
   - **Терминал:** установка описана здесь — https://code.claude.com/docs/en/overview. Потом в терминале `cd путь/к/папке` и `claude`.
3. **Скопируй первую команду** из `PROMPTS.md` (Phase 1) и вставь в Claude Code. Дождись, пока он закончит — это может занять долго. Он сам пишет код, тестирует его и собирает zip.
4. **Проверь результат.** В папке `dist/` появятся:
   - `drop01-deploy.zip` — файл для GoDaddy;
   - `DEPLOY-GODADDY.md` — пошаговая инструкция по загрузке, на английском и русском.
5. **Загрузи на GoDaddy** по этой инструкции: cPanel → File Manager → `public_html` → Upload → Extract → открыть `твойсайт.com/install.php`.
6. **Переходи к следующему этапу** — следующая команда из `PROMPTS.md`. После каждого этапа получаешь новый zip и загружаешь его поверх старого. Данные при этом сохраняются.

## Этапы

1. **Фундамент и вейтлист** — сайт-вейтлист работает по-настоящему: регистрации, общие голоса, дашборд, админка.
2. **Магазин** — каталог, корзина, оплата через Mollie (iDEAL, Apple Pay, карты), заказы в CRM, счета, письма.
3. **Доставка** — зоны Гронингена, окна, маршрут курьера, режим курьера.
4. **Деньги и маркетинг** — прибыль, BTW, промокоды, рефералка, брошенные корзины, поставщики, возвраты.
5. **По желанию** — автоматический WhatsApp, Tikkie API, Apple Wallet и так далее.

## Что понадобится от тебя

- **Хостинг:** тариф GoDaddy **Web Hosting (cPanel)**. Тариф «Website Builder» не подойдёт.
- **Mollie:** аккаунт на mollie.com. Для тестов хватит тестового ключа, для живых платежей нужна верификация бизнеса.
- **Почта для писем клиентам:** почтовый ящик на домене (GoDaddy или любой другой с SMTP).
- **Данные бизнеса:** название, KvK, BTW-номер, адрес склада, товары с фото и ценами. Записывай в `OWNER_INPUT.md`. Пока их нет, Claude Code поставит заглушки и демо-данные, которые потом удаляются одной кнопкой.

## Важно

- Тексты Terms, Privacy и Returns будут черновиками. Перед запуском их стоит показать юристу или бухгалтеру.
- Перед каждым обновлением скачивай бэкап: админка → Settings → System → Download backup.
